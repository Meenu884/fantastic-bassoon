# Fantastic Bassoon

Fantastic Bassoon is a playful browser game where you guide a musical hero through a glowing meadow of notes while avoiding shadowy squawks.

## Features
- Collect shimmering notes to earn points
- Dodge hazards and survive as long as possible
- Simple keyboard controls for quick play
- Built with plain HTML, CSS, and JavaScript

## How to Play
1. Open the game in a browser.
2. Use the WASD keys or arrow keys to move.
3. Collect 12 notes to win the round.
4. Press Enter to restart after a game over or victory.

## Run Locally
From the project folder, start a simple local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://127.0.0.1:8000/index.html
```

## Project Files
- index.html — game structure
- style.css — visual styling
- script.js — game logic and rendering
